# Changelog v3.2.0
## Updated to Cobblemon 1.8.2
- Updated the custom type implementation to be more in line with what Cobblemon does
- Added Lost Lore dex as a subdex of the national dex to prevent crashes in 1.8.2
## Added Custom Pokéballs!
### Mewtwo Ball
- This ball is from the first Pokémon movie!
- Ignores the current HP of the target for the catch rate calculation
- Meaning it behaves as if the Pokémon had one hp regardless of its actual hp
- _(translates to roughly a 2x catch rate at one hp and 6x at 100% hp)_
### Typing Ball
- This ball is from Pokémon: Typing Adventure
- It has a 5x catch rate boost on unown and 1x against every other Pokémon

## Smaller Additions, updates & fixes:
- Fixed riding _(for Clone Starters, Virus Groudon, Illusionary Rayquaza)_
- Fixed an issue with the Crystal & Shadow types appearing twice in the TM machine GUI
